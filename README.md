# TEDx Ideas Hub

WEBSITE BUILD PROMPT — TEDx P. Obul Reddy Public School

Create a premium, modern, highly polished official website for a TEDx event at P. Obul Reddy Public School, taking place on 21 November.

The website should feel like a real, professionally produced TEDx event website, not like a generic school website. The design should combine the sophistication of TED/TEDx with the youthful energy and creativity of a student-led event.
